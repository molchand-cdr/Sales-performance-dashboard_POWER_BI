# Sales-performance-dashboard_POWER_BI
This is a power bi end to end Project

This project showcases a Sales Performance Dashboard built in Power BI using a raw dataset of sales transactions. The dashboard provides a comprehensive view of business performance across multiple dimensions such as product lines, territories, deal sizes, and customer contacts.

✨ Key Features
--KPIs at a glance:

--Total Sales, Average Quantity Ordered, Average Price, Count of Orders, and Territories.

--Deal Size Analysis: Pie chart showing contribution of Small, Medium, and Large deals.

--Geographic Insights: Interactive world map highlighting sales distribution across regions (APAC, EMEA, Japan, NA, South America, Africa, Australia).

--Product Line Performance: Bar chart comparing sales across Classic Cars, Vintage Cars, Motorcycles, Trucks & Buses, Planes, Ships, and Trains.

--Customer-Level Insights: Tabular view of top customers with individual sales contributions.



🚀 Business Value
--This dashboard helps stakeholders:

--Identify top-performing product lines and regions

--Track sales trends over time

--Monitor customer contributions

--Support data-driven decision making with interactive insights

Trend Analysis: Line chart ranking territories across years (2012–2016) based on sales growth.

Interactive Visuals: Drill-down, filters, and slicers for dynamic exploration.
